Lapivelle / 隐私政策

隐私政策

本政策说明 Lapivelle 应用、本网站及咨询过程中如何处理信息。

更新于 2026 年 10 月 3 日

本页内容

适用范围应用中的信息故事与播放主动联系我们时访问本网站共享与外部服务保留与选择联系与更新

适用范围

本政策适用于 Facta Leopard 提供的 Lapivelle 应用、本网站及支持服务。Lapivelle 面向由成年人操作的安静晚间使用场景。

应用中的信息

Lapivelle 不要求账户，不包含第三方广告、分析 SDK、追踪 SDK 或社交功能，也不请求麦克风、相机、位置或联系人权限。应用不会要求儿童或其他用户填写个人信息。

语言、收藏、播放偏好和睡眠定时器选项保存在设备本地，不会发送到开发者运营的服务器。我们不提供云端账户，也不通过自己的服务器同步这些设置。

故事与播放

应用包含的文字、插画和音频在设备上使用。应用不录制你的声音，也不把阅读或收听内容发送到 AI 服务。内容可能通过常规应用更新提供。

“开发者的其他应用”的列表和说明包含在应用内。打开该页面时，可能会从 Apple 图片服务器加载图标。图片请求不包含故事内容或你的收藏。选择 App Store 链接后，会打开 Apple 的服务。

主动联系我们时

发送支持邮件时，我们会收到你的邮件地址、消息以及你自行提供的其他信息。我们用这些信息回复请求、调查问题或处理隐私咨询。邮件服务提供商负责邮件的传递和存储。

GitHub Issue 是公开帖子，不是私密支持信箱。请勿在其中发布个人或敏感信息。隐私相关请求请通过电子邮件提出。

访问本网站

本网站由 GitHub Pages 托管。GitHub 会出于安全目的记录访客的 IP 地址，具体处理方式见其隐私声明。

我们不会在网站中加入广告、访问分析、追踪 Cookie、第三方嵌入内容或远程字体。语言选择通过页面链接实现，不会保存访客画像。

GitHub 隐私声明

共享与外部服务

我们不出售个人信息，也不将应用偏好用于广告。App Store 分发和系统备份由 Apple 按其政策处理。GitHub 和邮件提供商依据各自的条款运营；打开外部链接会进入相应提供商的服务。

Apple 隐私政策

保留与选择

本地应用数据会保留到你更改设置或删除应用为止。根据 Apple 设置，设备或云端备份可能保留副本，我们不会收到这些备份。

支持邮件仅保留至处理请求及履行适用记录保存义务所需的时间。若要查询、更正或请求删除你发送的信息，请发邮件联系我们。我们无法访问仅存于你设备上的数据。托管安全日志的保留由 GitHub 管理。

联系与更新

隐私问题请联系 shteosis@gmail.com。如果你认为儿童曾通过支持渠道发送个人信息，也可以联系我们。处理方式发生变化时，我们会更新本页及其日期。
