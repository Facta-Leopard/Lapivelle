隱私權政策

本政策說明 Lapivelle App、本網站及諮詢過程中如何處理資訊。

更新日期：2026 年 10 月 3 日

本頁內容

適用範圍App 中的資訊故事與播放主動聯絡我們時瀏覽本網站分享與外部服務保存與選擇聯絡與更新

適用範圍

本政策適用於 Facta Leopard 提供的 Lapivelle App、本網站及支援服務。Lapivelle 是為成年人操作的安靜晚間使用情境而設計。

App 中的資訊

Lapivelle 不要求帳號，不含廣告、分析 SDK、追蹤 SDK 或社交功能，也不要求麥克風、相機、位置或聯絡人權限。App 不會要求兒童或其他使用者輸入個人資料。

語言、收藏、播放偏好與睡眠計時器選項儲存在裝置本機，不會傳送到開發者營運的伺服器。我們不提供雲端帳號，也不透過自己的伺服器同步這些設定。

故事與播放

App 內含的文字、插畫與音訊會在裝置上使用。App 不會錄下你的聲音，也不會將閱讀或聆聽內容傳送至 AI 服務。內容可能透過一般 App 更新提供。

主動聯絡我們時

寄送支援郵件時，我們會收到你的電子郵件地址、訊息及你自行提供的其他資訊。我們用這些資訊回覆請求、調查問題或處理隱私諮詢。郵件服務提供者負責郵件傳遞與儲存。

GitHub Issue 是公開貼文，不是私人支援信箱。請勿在其中張貼個人或敏感資訊。隱私相關請求請透過電子郵件提出。

瀏覽本網站

本網站由 GitHub Pages 代管。GitHub 會基於安全目的記錄訪客的 IP 位址，相關處理方式見其隱私權聲明。

我們不會在網站中加入廣告、瀏覽分析、追蹤 Cookie、第三方嵌入內容或遠端字型。語言選擇透過頁面連結運作，不會保存訪客個人檔案。

GitHub 隱私權聲明

分享與外部服務

我們不販售個人資料，也不將 App 偏好用於廣告。App Store 發佈與系統備份由 Apple 依其政策處理。GitHub 和郵件提供者依各自條款營運；開啟外部連結後，會進入對應提供者的服務。

Apple 隱私權政策

保存與選擇

本機 App 資料會保留到你更改設定或刪除 App 為止。依 Apple 設定，裝置或雲端備份可能保存副本，我們不會收到這些備份。

支援郵件只保存至處理請求及履行適用紀錄保存義務所需的期間。如要查詢、更正或請求刪除你寄送的資訊，請以電子郵件聯絡我們。我們無法存取僅存在你裝置上的資料。代管安全紀錄的保存由 GitHub 管理。

聯絡與更新

隱私問題請聯絡 shteosis@gmail.com。若你認為兒童曾透過支援管道傳送個人資料，也可以聯絡我們。處理方式變更時，我們會更新本頁及其日期。
